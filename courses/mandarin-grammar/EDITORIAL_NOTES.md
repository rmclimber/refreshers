# Mandarin editorial revision: 0.2-draft

Date: 2026-11-10. Scope: grammar claims, example naturalness, translations, and information density across the complete course and answer key. This is an AI editorial pass supported by teaching references, not independent human language review.

## Substantive changes

- Replaced the awkward engineer/busy contrast and the fragment 今天不做完 with natural, complete examples. The latter now distinguishes an unattainable result from choosing not to act.
- Clarified that question words stay in the answer's position; subject questions can naturally begin with 谁.
- Preserved the distinction between realized events, completed tasks, and situation updates. Added a past-state example without 了 and a 没有...了 example so the quick reference does not suggest universal rules.
- Reworked duration around a more idiomatic example, qualified the continuing-activity inference, and introduced 次 versus 遍 before the parsing task uses it.
- Clarified descriptive versus potential complements, hearing versus understanding, and the background-action use of 着. Retained context-dependent readings rather than presenting these as one-to-one English equivalents.
- Added a 把 example elaborated with 一下, the negative detail-focus 是...的 pattern, and explicit sufficient/necessary-condition explanations.
- Used 短 for route length; removed an unwarranted “another glass” implication from 还; aligned the parsing-task translation with its source sentence.
- Removed repeated coaching and tightened explanations while retaining the diagnostic, all construction units, both application tasks, and the answer key. The revised teaching text is slightly shorter despite the added contrasts.
- Removed 了解 from the pronunciation example: standard traditional conversion produces 瞭解, obscuring an example intended to teach the reading of 了. 受不了 works in both scripts; 去不了了 now explicitly distinguishes liǎo from final le.
- Corrected OpenCC's contextual error 彆着急 to 別着急 through a narrowly scoped course-metadata override. Imperative “don't” takes 別; 彆 is used in other words such as 彆扭. Code spans and link targets remain protected from both conversion and overrides.

## Reference checks

Targeted checks used Oxford CTCFL's [descriptive 得](https://www.ctcfl.ox.ac.uk/materials_grammar-exercises_verb-de/), [potential complements](https://www.ctcfl.ox.ac.uk/materials_grammar-exercises_pvc/), [把](https://www.ctcfl.ox.ac.uk/materials_grammar-exercises_ba/), [comparatives](https://www.ctcfl.ox.ac.uk/materials_grammar-exercises_comparatives/), [了](https://www.ctcfl.ox.ac.uk/materials_grammar-exercises_le1/), and [agentless/passive-like constructions](https://www.ctcfl.ox.ac.uk/materials_grammar-exercises_bei2/); ChinGram's [teacher's guide to 着/著](https://chingram.upol.cz/grammar/aspectual-particle-zhe-%E7%9D%80/teachers-guide-%E7%9D%80-%E8%91%97); EdUHK's [contextual tones of 一](https://corpus.eduhk.hk/mandarin_pronunciation/?page_id=1286); and Taiwan's Ministry of Education [dictionary entry for 別](https://dict.concised.moe.edu.tw/dictView.jsp?ID=1435&q=1), including its imperative meaning. These are cross-checks, not a claim that every teaching shortcut in a reference applies without exceptions.

## Editions and review status

The canonical text remains simplified Mandarin with broadly mainland usage. Traditional output continues to use OpenCC standard `s2t`, which can produce forms such as 喫, 爲, and 裏. This is script conversion, not regional adaptation; no regional vocabulary changes were introduced.

Version 0.2 remains a draft. Independent human review should focus on discourse-sensitive 了 readings, context-dependent complement interpretations, and the naturalness of both script editions.
